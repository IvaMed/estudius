================================================================================
ESTUDIUS - Resumen de entrega
================================================================================

QUE ES
------
Plataforma web para buscar profesores particulares, ver su perfil (materias,
horarios, modalidad virtual/presencial) y reservar clases. Los administradores
mantienen el catalogo; los alumnos registrados reservan y guardan favoritos.

SLOGAN
------
Si queres estudiar, Estudius es el lugar.

COMO ARRANCAR
-------------
1) Doble clic en iniciar-estudius-red.bat  (PC + celular en Wi-Fi)
   o
2) cd Backend -> npm install -> npm start -> http://localhost:3000
