Conectar Estudius desde el celular

ERR_SSL_PROTOCOL_ERROR aparece cuando el navegador usa https:// pero el puerto 3000 solo habla http (sin cifrado).

Solución A — HTTP (recomendado):

  1. Misma Wi‑Fi que la PC.
  2. Escribí en Chrome completo: http://TU-IP:3000 (con http://, no solo la IP).
  3. Si Chrome cambia a https solo, desactivá en Ajustes → Privacidad → «Usar siempre conexiones seguras».

Solución B — HTTPS (puerto 3443):

  1. Abrí https://TU-IP:3443
  2. Chrome mostrará «No es seguro» → Avanzado → Continuar (certificado local).

Probá primero: /api/health
